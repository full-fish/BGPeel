Features and Fine-Tuning Guide

All of BGPeel's features and settings in one place. The defaults work for most images; look up only the item you need when a result isn't quite right.

→ Go to the BGPeel tool

1. Adding images

Drag and drop
Drop images anywhere on the page, not just on the drop area. Many at once is fine.
Whole folders
Click “choose a folder” or drop a folder to add everything in it, including subfolders. Images are sorted in folder order, and the zip download keeps the same folder structure.
Paste
Paste a screenshot with Ctrl+V (⌘V on a Mac).
Supported files
Any image your browser can open, such as PNG, JPG, WebP, BMP or GIF (first frame). Images are never uploaded to a server.

2. Basic settings

Background color — Auto-detect (default)
For each image, the most common color along the border is used as the background. It works even if the object touches the border. After conversion, each card shows the detected background color.
Background color — Pick a color
Only images whose border is close to this color (within 80 per channel) are processed; others are skipped. The exact color to remove is still measured from each image's border. Use it to process only one background color out of a mixed batch.
Background type — Auto (default)
Chosen per image from its background. Vivid colors like magenta, green or blue use “Vivid solid”; dull or pale colors like dusty pink, white or gray use “Dull / pale solid”. Black backgrounds are skipped because outlines would be erased too.
Background type — Vivid solid
For vivid backgrounds like magenta, green or blue. Removes color fringes and glows cleanly. Images with dull backgrounds are skipped.
Background type — Dull / pale solid
For dusty pink, white, gray or black backgrounds. Pixels are judged only by how different they are from the background, so object areas with similar colors may be removed too. Choose it yourself when you need to remove a black background.
Background type — Keep background
Leaves the background as is. Use it with the size and format settings under “Downloading” to just resize images or convert them to JPG, PNG or WebP. Fine-tuning is not used in this mode. See Resize images for details.

3. Fine-tuning

Open “Fine-tuning” to change the items below with sliders or numbers. The number of changed items appears as “n changed from default”, and “Reset to defaults” resets only fine-tuning, keeping the background color and type. After you change settings, the convert button becomes “Convert again with new settings”.

General (both background types)

Remove threshold LO · default 0.12 (0–0.9)
Pixels that are almost entirely background become fully transparent. Raise it to also clear glows and edges that are only partly background; lower it to remove less. It always stays below the keep threshold.
Keep threshold HI · default 0.5 (0.1–1)
Pixels with at least this much object color stay fully opaque; pixels between the two thresholds become semi-transparent. Raise it for softer edges; lower it for crisper edges, which may keep some background tint.
Edge cleanup width EDGE_PX · default 4px (0–16)
Within this distance of transparent areas, the blended-in background color is subtracted to restore the object's own color. Raise it if a colored line remains around outlines.
Light background detection TINT_TOL · default 40 (0–120)
How far to treat pale, whitish glows and sparkles as background, only when they are connected to the background. This is also what removes the Nano Banana mark in the bottom-right corner. Raise it if they remain; lower it if object edges get erased.

Vivid solid backgrounds only

Also remove colored glows REMOVE_GLOW · default on
Removes purple and blue glows connected to the background. Turn it off to keep light effects; the three glow settings below then have no effect.
Glow color range GLOW_HUE · default −85° to +30°
With the background hue at the center (0°), only glows within this hue range are removed. If a sky-blue glow remains, widen the start to the left. Objects of that color may be erased too.
Glow minimum saturation GLOW_MIN_SAT · default 0.3 (0–1)
Colors duller (grayer) than this are treated as part of the object and kept. Lower it to remove duller glows; raise it to remove only vivid ones.
Glow minimum brightness DARK · default 80 (0–255)
Colors darker than this are treated as outlines and kept. Lowering it removes darker glows but may trim outlines.
Fix half-tinted pixels REPAIR · default on
Pixels where the background color bled in halfway (like pink specks on sand, orange or yellow drips) are restored to the nearby object color and made semi-transparent.
Search distance for the fix REPAIR_PX · default 40px (0–100)
40 suits 2048px pixel art (one art pixel ≈ 10px). Raise it if tinted spots remain; higher values are slower.

Dull / pale solid backgrounds only

Color difference from background DIST_TOL · default 160 (20–255)
Colors at least this different from the background are kept fully. Raise it if background color remains around glows; lower it if the object becomes semi-transparent.

With the background type on Auto, both type-specific groups are shown, and each image uses only the group for the type it was detected as.

4. Converting and reconverting

Convert
Processes the added images. Several are processed at once (one at a time on phones, up to four on computers depending on the CPU), and the page stays responsive meanwhile.
What gets converted?
Selected cards if any (“Convert n selected”); otherwise only newly added images (“Convert n remaining”); otherwise everything. Other results are kept.
Selecting cards
Click a card image to select it. Shift-click selects everything from the last clicked card to this one. “Select failed” selects only skipped or failed cards, and “Deselect” clears the selection.
Stop
Finishes the images in progress and stops. Continue the rest with “Convert n remaining”.
Removing cards
The × at a card's top right removes that card; “Clear list” asks for confirmation, then removes all of them.

5. Checking results

Compare with the original
Hover over a card image (or press and hold on a phone) to see the original. “Show originals” switches every card at once.
Large view
The magnifier button on a card opens it full screen. Hold to see the original, use ←/→ for the previous or next image, and press Esc or click outside to close.
Preview background
Choose checkerboard, black or white. Black or white makes leftover background color at the edges easy to spot.
Card size and sidebar position
“Card size” −/+ fits more or fewer images on screen, and ⇄ moves the settings sidebar left or right on wide screens.

6. Downloading

Format — PNG (default), WebP or JPG
Only PNG and WebP keep a transparent background. WebP is often smaller than PNG, and browsers that cannot save WebP give you a PNG instead. JPG cannot store transparency, so transparent areas are filled with white; if you removed the background, choose PNG or WebP. The format applies to every card.
Download size
Original size, 1024, 512, 256, 128 or 64px, or a custom size. Scales by the long side and keeps the aspect ratio; never enlarges.
Reduce to 256 colors
Makes pixel art and icons much smaller, but can cause banding on smooth gradients like photos. Available for PNG only.
All cards or card by card
Changing size or 256 colors in the top settings updates every card; after that you can change cards one by one. Each card shows “original size and file size → download size and file size” (the download file size appears after the first download).
One by one or as a zip
Use the Download link on each card, or “Download zip” for everything. The zip keeps the folder structure you added, and duplicate names get a number.

7. When an image is skipped

Skipped cards show the reason.

No clear background color on the border
The object covers almost the whole border. Regenerate with some background margin.
Border is not the chosen background color
You picked a background color, but this image's background is a different color.
Background is near black
Black backgrounds are skipped in Auto because outlines would be erased too. Choose “Dull / pale solid” to process them anyway.
Background is not a vivid solid color
You chose “Vivid solid”, but the background is dull. Switch to “Auto” or “Dull / pale solid”.

8. What is saved and what isn't

  • Settings (background color, fine-tuning, download size and format, view options) are remembered in this browser and stay the same next time.
  • Added images and results live only in this tab's memory. The page asks before you reload or close the tab.
