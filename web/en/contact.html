Contact

BGPeel takes questions by email. The one developer behind it reads and answers every message.

Email

manseon94@gmail.com

What to send

  • Bug reports: When conversion stops, results look wrong or a button doesn't work.
  • Images that don't come out clean: When an outline remains or the object gets eaten even after adjusting settings. These cases help improve the algorithm more than anything.
  • Feature ideas: Features you'd like or things that get in your way.
  • Errors in the guides: When a guide is wrong or another service's specs have changed.
  • Advertising and partnerships: Any other business inquiries.

When reporting a bug, please include

  • Your device and browser (e.g. Chrome on Windows 11, Safari on iPhone)
  • What you clicked, in order
  • Any message shown on the card (e.g. “Skipped” and the reason)
  • Any values you changed under Fine-tuning
  • If possible, the image that caused the problem

About sending images

BGPeel never sends images to a server, so I have no way to see the images you processed. To reproduce a problem, please attach the image to your email. Images you send are used only to investigate and fix the problem and are never published. If an image can't be shared, another image that shows the same problem works just as well.

Worth checking first

  • Outlines left or objects eaten: Parts of the object disappear, Color fringes
  • Leftover shadows or gradients: A shadow is left behind, Gradient backgrounds
  • All articles: Guides
