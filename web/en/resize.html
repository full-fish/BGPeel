How to use it

  1. The link above opens the tool with the background type set to “Keep background”. If you came in another way, choose “Keep background” yourself.
  2. Drop images or a folder. Many images and subfolders work at once.
  3. Under “Download size”, pick 1024, 512, 256, 128 or 64px, or choose “Custom” and type a size.
  4. Under “Format”, choose JPG, PNG or WebP.
  5. Click “Convert”, then use each card's Download link or “Download zip” to get everything.

How is the size changed?

  • By the long side: the longer of width and height is fitted to the size you pick, keeping the aspect ratio. For example, a 4000×3000 photo at 1024 becomes 1024×768.
  • Never enlarged: images smaller than the chosen size stay at their original size.
  • Clean downscaling: large reductions are done in halving steps, so thin lines don't break up or turn jagged.
  • Card by card: after setting a size for all images, you can give individual images a different size. Each card shows “original size → download size” with file sizes.

Which format should I use?

JPG
Best for photos and opens everywhere. It cannot store transparency, so transparent areas are filled with white.
PNG
Keeps transparency with no quality loss. For icons and pixel art, turn on “256 colors” for much smaller files.
WebP
Keeps transparency and is often smaller than PNG. Good for images going on a website. Browsers that cannot save WebP give you a PNG instead.

If you need a transparent background, choose PNG or WebP.

Want to remove the background too?

Leave the background type on “Auto” to remove solid backgrounds like magenta or green, make them transparent, and then resize the same way. See Magenta background to transparent PNG and the features guide.
